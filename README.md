# HOA THANH THÚY - Website tiệm hoa tươi Đà Lạt

Website: https://www.hoathanhthuy.net · Gọi/Zalo: 0918.814.544 · Đường Tô Ngọc Vân, Phường Xuân Hương - Đà Lạt, Lâm Đồng

Kho này chứa **bản tĩnh** của website (song ngữ Việt - Anh) phục vụ qua GitHub Pages với tên miền tùy chỉnh `www.hoathanhthuy.net` (file `CNAME`). Ở chế độ tĩnh, yêu cầu đặt hoa và báo giá sỉ được soạn sẵn để gửi qua Zalo/điện thoại. Bản đầy đủ có trang quản trị và máy chủ PHP (lưu đơn, tra cứu & duyệt ảnh, sao lưu 2 nơi) được quản lý riêng.

- Nội dung: `data/site.json` (24 mẫu hoa, 21 loài trong từ điển, 16 loại hoa sỉ...)
- Minh họa hoa SVG: `assets/flora.js`
- Cập nhật: thay `index.html`, `data/site.json`, `assets/*` rồi đẩy lên nhánh `main`.
