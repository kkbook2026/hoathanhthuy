Kho này chứa **bản tĩnh** của website (song ngữ Việt - Anh) phục vụ qua GitHub Pages với tên miền tùy chỉnh `www.hoathanhthuy.net` (file `CNAME`).

- Trọng tâm: bán buôn hoa cắt cành cho cửa hàng toàn quốc, xuất khẩu hoa tươi, cung ứng định kỳ cho doanh nghiệp; bán lẻ tại Đà Lạt.

- Nội dung: `data/site.json` · Minh họa hoa SVG: `assets/flora.js` · Ảnh tải lên: `uploads/`.
